# 小项目1：真实负荷预测基准实验

目标：在同一真实数据、同一预测时间点和同一回测窗口下，比较回归模型与时序预测模型。

## 数据来源与处理

数据：[UCI ElectricityLoadDiagrams20112014](https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams20112014)，370个葡萄牙用电点，每15分钟一条，单位为 kW。引用：Trindade, A. (2015), DOI: 10.24432/C58C86；许可：CC BY 4.0。

下载官方 ZIP 到 `data/uci_raw/electricityloaddiagrams20112014.zip`：

```powershell
curl.exe -L --retry 3 --fail --output data/uci_raw/electricityloaddiagrams20112014.zip https://archive.ics.uci.edu/static/public/321/electricityloaddiagrams20112014.zip
```

预处理只读取压缩包中2014年4月至9月的窗口，不展开678 MB的完整文本。将每小时4个15分钟 **kW功率读数求平均**，得到小时平均功率；不能将它们直接求和当作小时功率。此窗口避开原数据说明中的3月和10月夏令时特殊时段。默认在非零率不低于98%、平均负荷大于1 kW的用户中，按负荷规模选3个代表用户。输出所选用户编号和统计量到元数据文件。

```powershell
python experiments/real_load_benchmark/prepare_data.py
```

## 公平的预测任务

每天午夜刚得到该时刻负荷后，预测未来第1至24小时负荷。所有模型使用同一批午夜预测起点，分别在以下三个14天预测起点窗口回测；每个窗口最后一个目标时间是次日00:00：

```text
折1：2014-08-01 至 2014-08-14
折2：2014-09-01 至 2014-09-14
折3：2014-09-15 至 2014-09-28
```

每折重新训练模型；训练标签的目标时间不能晚于该折第一个预测起点。每折测试期间允许使用新到达的真实历史负荷，但不更新模型参数。UCI 数据不含天气，所有模型都只使用负荷历史和日历信息。

| 模型 | 训练输入 | 单次输出 | 原理 |
|---|---|---|---|
| 昨日同期、上周同期 | 目标时刻前24/168小时负荷 | 1个负荷值 | 季节性朴素基线，无训练参数 |
| Ridge（仅历史特征） | 每个目标时刻的7个负荷历史特征 | 1个负荷值 | 线性回归对照，用于观察日历特征的增益 |
| Ridge | 每个目标时刻的12个日历与历史统计特征 | 1个负荷值 | 标准化后的线性回归，L2约束系数 |
| HistGradientBoosting | 与 Ridge 相同的12个特征 | 1个负荷值 | 顺序叠加树，拟合非线性规律和交互作用 |
| 直接线性序列模型 | 截至起点的168小时完整序列 | 同时输出未来24小时 | 不分解序列的多输出线性模型，作为 DLinear 风格模型的对照 |
| DLinear 风格 | 截至起点的168小时完整序列 | 同时输出未来24小时 | 移动平均分解趋势与残差，两组线性权重联合拟合；本实验用带L2约束的最小二乘训练，不使用原论文的神经网络训练代码 |
| 季节性 ARIMA | 截至起点的完整小时序列 | 递推输出未来24小时 | 本实验固定为 SARIMA(1,0,0)×(1,0,0,24)，每折估计参数，每天更新已观测状态 |

Ridge 与树模型的12个特征：预测提前量、目标小时和星期的正余弦编码、是否周末、预测起点负荷、目标时刻的昨日和上周同期负荷，以及过去24/168小时统计量。所有负荷特征的时间戳均不晚于预测起点。

## 运行与结果

```powershell
python experiments/real_load_benchmark/benchmark.py
python -m unittest discover -s tests -v
```

`outputs/real_load_benchmark/` 下会输出逐时预测、分用户/分折/分提前量指标、拟合耗时、模型比较图和逐用户预测图。主指标为 MAE、RMSE、nMAE 和 MASE；不以 MAPE 作为主指标，因为个别低负荷时段会使百分比误差不稳定。nMAE 以每折训练集平均负荷归一化，MASE 以训练集昨日同期平均绝对误差归一化。

`--clients MT_001` 可只跑指定用户；`--folds 1` 可先跑一折；`--skip-sarima` 可在调试时跳过耗时较高的 SARIMA。

## 本次真实数据结果与实验区别

以下为三折、每位用户 1008 个逐小时预测点的总体 nMAE（数值越低越好）：

| 用户 | 昨日同期 | Ridge | 树模型 | 直接线性序列 | DLinear 风格 | SARIMA | 总体最优 |
|---|---:|---:|---:|---:|---:|---:|---|
| MT_140 | 23.16% | 34.99% | 27.58% | 41.98% | 42.15% | 34.81% | 昨日同期 |
| MT_233 | 5.28% | 4.80% | 5.04% | 4.36% | 4.39% | 5.32% | 直接线性序列 |
| MT_273 | 5.46% | 5.20% | 5.47% | 5.17% | 5.18% | 5.53% | 直接线性序列 |

MT_140 在第三折发生明显的高负荷波动，昨日同期的 nMAE 从前两折的约 5.41%、6.67% 跳到 57.41%；这说明必须看逐折稳定性，不能只看总体排名。MT_233、MT_273 上，直接线性与 DLinear 风格模型很接近：两者都属于线性映射，而趋势与残差之和就是原序列，分解本身不保证增加表达能力；此处差异主要来自不同特征表示在 L2 正则下的拟合。MT_273 的模型差距尤其小，不能仅凭这三折断言某模型在其他用户上更优。

本实验的控制对照分别是：Ridge 仅历史特征 vs Ridge 加日历特征（考察日历特征）；直接线性序列 vs DLinear 风格（考察分解）；Ridge vs 树模型（相同表格特征下考察非线性）。表格模型与序列模型的输入不相同，跨类别排名不能单独归因于模型结构。详细数值和预测轨迹见 `outputs/real_load_benchmark/experiment_report.md` 与对应 CSV、PNG。

## 阅读论文时的实验问题

1. 树模型能否在真实数据中稳定优于线性回归？差异集中在什么小时或负荷峰值？
2. 去掉目标日历特征后 Ridge 是否退步？将完整168小时序列分解为趋势和残差后是否优于不分解的直接线性模型？
3. SARIMA 与表格回归所需的数据输入和拟合方式有什么差别？
4. 对不同负荷规模用户，原始 kW 误差和归一化误差会给出相同排名吗？
5. 所有模型是否都优于简单的昨日或上周同期基线？
